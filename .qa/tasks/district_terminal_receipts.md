## Ручная приёмка

- [x] Утром в терминале видны поступившие коробки до сканирования: «Без номера», описание, дата поступления; номер 000 и дата регистрации день 0 не показываются.
- [x] После сканирования существующая строка получает номер выдачи; второй строки той же посылки нет.
- [x] До прихода клиента доступна «Потеряли»; «Забрали» и «Отказались» доступны после начала визита.
- [x] Уничтожить незарегистрированную коробку: запись остаётся, потеря автоматически не объявляется. Заявить её вручную, открыть архив и проверить сохранённую отметку.
- [x] Оставить поступившую коробку без регистрации до истечения срока: следующим утром показывается просрочка и её штраф; коробка остаётся физическим предметом. Повторное открытие терминала и ожидание не повторяют штраф.
- [x] Поздно зарегистрировать сохранившуюся коробку: получатель может прийти и получить её по обычным правилам.
- [x] Проверить читаемость длинного статуса «ПРОСРОЧЕНА РЕГИСТРАЦИЯ», кнопок и даты при используемом разрешении экрана.
