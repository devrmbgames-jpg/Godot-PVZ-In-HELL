# Район — ручная приёмка согласованного сохранения

Status: **ACCEPTED** — решение владельца 2026-10-15.

Принято владельцем 2026-10-15 по сообщению «Закрой все задачи где OWNER_QA». Ранее реализованный объём закрыт общей приёмкой; новые замечания остаются отдельными задачами. Поштучный прогон всех сценариев и новая визуальная QA агентом не заявляются.
Пункты ниже закрыты общей приёмкой владельца, а не отчётом о поштучном прогоне. Прежние пометки ожидания ручной QA относятся к контрольной точке до этого решения.

Owning task: [Согласованный снимок и повтор ночной записи](../../.agents/tasks/completed/district_save_schema_3.md).

Проводит владелец в отдельном тестовом прохождении/слоте. Перед проверкой несовместимых
файлов сохранить копии; рабочие сохранения владельца не использовать. Headless проверки
не доказывают понятность сообщений, внешний вид или удобство этих действий.

- [x] Старый/newer/повреждённый файл сопровождается понятным сообщением об отказе.
  После отказа обычное продолжение и следующая ночь не перезаписывают исходный файл.
- [x] Выбор корректного ручного слота позволяет восстановить прохождение, сохраняя
  защиту ранее отвергнутого автоматического слота.
- [x] Явное «Новое прохождение» позволяет создать новое сохранение; следующий перезапуск
  восстанавливает именно новое прохождение. Действие явно выбрано владельцем.
- [x] После полного закрытия игры и загрузки заметка остаётся обычным текстом, прочитанные
  уведомления сохраняют состояние, обещание и результат торга не появляются повторно.
- [x] При следующем ночном переходе ожидающая мебель, входящая партия и обратный груз
  сохраняют однократную оплату/обработку; погибший NPC не воскресает и не дублируется.

До решения владельца обязательная ручная приёмка открыта; owning task не архивировать.
Результаты и замечания записать здесь после фактического выполнения.
