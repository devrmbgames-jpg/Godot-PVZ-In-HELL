## Приёмка владельцем

- [x] Поле ReceivingZone.truck_parking указывает на TruckParking. Стоянка находится в авторской зоне DebugMarkers/CarZone; машина не перекрывает дверь, нужный проход или склад.
- [x] Перемещение/поворот TruckParking меняет место/поворот машины. Пользовательская сетка навигации сохранилась.
- [x] Утром появляется одна машина, существующая дверь открывается. Прибытие/движение не воспроизводятся.
- [x] В car.tscn список cargo_slots ссылается на 12 маркеров CargoSlots и задаёт порядок нижних/верхних мест. Изменение маркера отражается на размещении груза.
- [x] Коробки доступны для ручного выноса: не застревают в стенках, не проваливаются через пол и не перекрываются при укладке.
- [x] При заполнении кузова поставка ждёт. Вынос коробок освобождает место для остатка той же партии; долгое утро не создаёт лишние посылки.
- [x] В принятом прежнем контракте терминал показывал поступления до регистрации; номер выделялся отдельно. Новый контракт ниже заменяет этот пункт.
- [x] Длительный перезапуск с частичной поставкой сохраняет поступившие коробки и остаток без повторного груза.

Запрет начала смены до разгрузки, игрок в кузове, финальное закрытие двери и обратный груз принадлежат следующим задачам. Отрисовка и субъективное удобство не проверялись автоматически.

## Новый контракт автоматической регистрации — manual NOT_RUN

Связанная [задача](../../.agents/tasks/package_automatic_arrival_registration.md) выполняется отдельно; предыдущая общая приёмка не подтверждает новые сценарии.

- [ ] Не брать сканер: каждая реально появившаяся на выгрузке коробка сразу имеет номер и обе даты в терминале.
- [ ] При занятом кузове ещё не появившиеся коробки не имеют строк/номеров; освобождение места создаёт их по одному без дубликатов.
- [ ] Получатель приходит и принимает собственную коробку без сканирования; следующим утром нет штрафа за отсутствие сканирования.
- [ ] Первое и повторное чтение сканером показывают тот же номер, не меняя дату регистрации.
- [ ] Сон/загрузка сохраняют номера. В поддерживаемом старом снимке живая поступившая коробка без номера регистрируется один раз; отсутствующая коробка не появляется заново.
