## Цель

Провести пустой цикл Morning → Day → Evening → Night → Morning через действия в мире.

## Работы

- [ ] Создать единственный CurrentDayPhase и DayIndex, типизированные запросы перехода и правила допустимости.
- [ ] StartShift переводит Morning в Day; окончание обязательных customer events разрешает Evening.
- [ ] Для пустого прототипа явно задать политику пустого расписания и доступный игроку переход; позже подключить настоящее расписание.
- [ ] Evening разрешает SleepPoint; Night выполняет отдельный переход к Morning.
- [ ] Проверять phase permissions в действиях; предусмотреть hooks завершения дня и сохранения для задачи 21.

## Критерии готовности

- Morning/Evening не ограничены таймером, Day заканчивается по событиям.
- Цикл проходим без debug-команд и перезапуска; повторный запрос не дублирует переход или DayIndex.

## Проверки

GUT: допустимые/запрещённые переходы, повторный запрос, отсутствие дневных событий утром; walkthrough пустого цикла. Общие команды и правила завершения — в [README](README.md).

## Границы

Без сохранений и настоящих customer events; их владельцы — задачи 11 и 21. Сохранять Godot physics authority, GECS data/behavior boundaries и read-only addons. Выполненные основания переиспользовать, а не создавать заново.
