Сделать общий выбор доступных действий для предметов, инструментов и окружения с понятной подсказкой.

## Работы

- [ ] Сохранить дистанцию, направление и LOS; добавить детерминированный приоритет кандидатов и доступности действий.
- [ ] Описать типизированный контракт доступного действия и его выполнения; подключить grab как существующий обработчик.
- [ ] Разрешить F/use и контекст инструментов: Scanner использует ЛКМ, Marker использует ПКМ; документировать способ бросить/вращать активный инструмент без конфликта.
- [ ] Задать порядок: контекст инструмента → grab для обычного предмета → обычная атака; edge-событие выполняется максимум один раз, исходный input не обнуляется потребителем.
- [ ] Добавить прицел, доступные prompt и ненавязчивое выделение цели; UI только читает gameplay state.

## Критерии готовности

- За стеной и вне радиуса действий нет; prompt соответствует доступному обработчику.
- Один ввод не выполняет одновременно scan+throw, draw+rotate или throw+attack; снятие/удаление инструмента возвращает обычное управление.

## Проверки

GUT: приоритеты, недоступность, одно выполнение edge и cleanup; регрессии grab; ручная проверка prompt и курсора. Общие команды и правила завершения — в [README](README.md).

## Границы

Без полноценного framework контекстов управления, если достаточно небольшого контракта. Сохранять Godot physics authority, GECS data/behavior boundaries и read-only addons. Выполненные основания переиспользовать, а не создавать заново.
