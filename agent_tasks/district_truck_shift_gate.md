# Машина — разгрузка и условия начала смены

Status: **PLANNED**

Родительский этап: [Утренняя машина](district_morning_truck.md). Порядок выполнения: [общая задача](district_service_update.md).

Зависимости: [Машина — утреннее появление и входящие коробки](district_truck_morning_spawn.md).

## Task state

### Goal

Разрешать начало смены только после завершённой поставки, разгрузки/ручной потери и выхода игрока из кузова.

### Current

Входящая партия должна быть готова из зависимости. Проверка разгрузки и безопасное закрытие двери ещё не реализованы.

### Validation

Эта выделенная задача ещё не прошла приёмку. Ранее выполненные проверки в Current или родительском файле — контрольные точки; новые проверки записывать только после фактического запуска.

Parser и регрессии недопоставки, выноса/возврата коробки, отсутствующего тела, ручного LOST и игрока внутри; ограниченный headless lifecycle машины.

### Owner QA / blockers

Владелец проверяет сообщения и безопасность выхода из кузова.

## Границы и владельцы

- Грузовая область машины, `content/services/gameplay/day_phase_service.gd` и прямое UI причины запрета.
- Контракт ручного LOST, записи входящей партии и обработчик закрытия/диспавна машины.

Применять по области: [godot-physics-4.7](../.agents/skills/godot-physics-4.7/SKILL.md), [game-ui-ux](../.agents/skills/game-ui-ux/SKILL.md).

## Работы

- [ ] Использовать один источник причин запрета для UI и фактического начала смены: незавершённая поставка, невынесенные коробки, игрок в кузове.
- [ ] Считать коробку разгруженной после физического выхода из грузовой области. Отсутствие или уничтожение тела требует ручного LOST игроком.
- [ ] Показывать понятную причину и количество оставшихся коробок; отсутствующая до регистрации коробка доступна для ручного заявления.
- [ ] Не закрывать дверь при игроке внутри. После принятого начала смены закрыть дверь и диспавнить машину конечным lifecycle.
- [ ] Предусмотреть вызов обработки обратного груза до смены MORNING; финансовые операции реализует следующая задача.

## Критерии завершения

- Уничтоженную до регистрации коробку можно вручную отметить LOST и снять требование разгрузки.
- UI и исполнение смены согласованы; дверь не запирает игрока, отъезд не удерживает смену бесконечно.

Выполнять только этот ограниченный результат, объединяя связанные чтения, правки и проверки. Не расширять задачу соседними функциями. Закрыть её собственные Status/Current/Validation, сохранить связный результат коммитом и обновить следующее действие в общей задаче. Завершение этой задачи само по себе не закрывает родительский этап.
