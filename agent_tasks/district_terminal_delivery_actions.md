## Task state

### Goal

Подключить авторские уведомления и раздел доставки к постоянным предложениям, показывая только известные системе сведения.

### Current

Авторские `_alert_*` и `_delivery` подключены к постоянным опубликованным записям. Строка запрашивает принятие/отказ по `job_id` через сервис; повтор идемпотентен. Подробности показывают адрес, согласованную доплату, срок и статус. Ночью и при недоступной коробке/получателе кнопки отключены, причина показана в описании. Отказ терминальному предложению не переносит обычный визит и не изменяет коробку/деньги.

`TerminalPackageNoticeService` выделяет стабильные события штрафа, жалобы и доставки. Один приоритет управляет одной иконкой: подтверждённая санкция, жалоба/принятое обязательство, предложение/обновление доставки. Чтение видимых подробностей снимает текущие уведомления и сохраняет `read_event_ids` в истории коробки. Новое решение по жалобе/изменение статуса доставки имеет новый ключ; пересборка списка и загрузка не возвращают прочитанное событие.

Сервис проецирует только явно опубликованные сведения в `TerminalDeliveryInfo`, не передавая UI сценарий или приватное обещание. Модальный фокус получает выбранная строка; пересборка сохраняет посылку фокуса, закрытие освобождает UI-фокус. Сцены/имена узлов владельца сохранены. Родительский этап остаётся открытым: личные диалоги и окончательная связка выполнения — следующие задачи.
