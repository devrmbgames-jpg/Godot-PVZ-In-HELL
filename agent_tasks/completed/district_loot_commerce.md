## Работы: лут

- [x] Проверить появление лута коробок и NPC возле стены, в углу и рядом с другими предметами.
- [x] Использовать общий расчёт безопасного положения: опора на пол и проверка полной физической формы предмета, включая трансформации коллайдеров.
- [x] Проверять максимум 16 заранее заданных близких кандидатов на предмет. Без широкого поиска уровня и неограниченного случайного перебора.
- [x] Учитывать положения предметов, выбранных в той же партии, до следующего физического кадра, чтобы дроп не появился взаимно пересекающимся.
- [x] Неразмещённый остаток сохранять для повторной попытки с ограниченной частотой. Невозможность размещения не уничтожает предмет и не помечает всю партию успешно выпущенной.
- [x] Состав дропа и ID фиксировать один раз; повторная попытка, удаление источника и сохранение/загрузка не создают вторую партию.
- [x] Не переносить эти проверки в постоянный AI-такт: они исполняются при появлении предметов и ограниченном повторе.

- [x] Разрешить торговлю утром, днём и вечером и согласовать расписание постоянного торговца с доступностью услуги. Техническая фаза ночного сна не становится торговой сменой.
- [x] Добавить авторский признак возможности доставки крупногабаритной мебели. Вид предмета — мебель, признак явно включён в определении.
- [x] Проверять право доставки в сервисе покупки, а не только видимость кнопки. Еда, аптечки и прочие мелкие товары её не предлагают.

- [x] Использовать безопасное размещение и повтор при занятой площадке; не терять заказ и не превращать доставку в автоматическую установку мебели.
- [x] Сохранять правильный захват/освобождение UI-фокуса и управления при попапе.

## Критерии завершения

- Лут не пересекает стены, пол и соседние предметы при появлении. Если свободного места нет, он корректно ожидает возможности размещения.
- Смерть, вскрытие коробки и повторные попытки дают предусмотренное количество предметов ровно один раз.
- Сохранение/загрузка не теряет ожидающий остаток и не создаёт повторный дроп.
- Живой торговец предлагает услуги утром, днём и вечером.
- Попап доставки показывается только для подходящей крупной мебели, с доплатой 100$.
- Отмена/нехватка денег не создают покупку; доставка на следующее утро создаёт один предмет на авторской площадке.
- Существующие самовывоз, переноска и размещение мебели сохраняют свои контракты.
