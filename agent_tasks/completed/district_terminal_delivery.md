## Данные и границы знаний

- Заметка принадлежит стабильному ID истории посылки; переиспользуемый номер выдачи не является её ключом.
- Строка терминала читает известные сведения из постоянной записи, а не только из живой коробки.
- Запись о поступлении позволяет показать ещё не зарегистрированную коробку и заявить потерю. Она не регистрирует посылку и не резервирует номер.
- Предложение/обязательство связывается со стабильными ID посылки, визита и NPC; хранит источник `TERMINAL/PERSONAL`, день, срок, цену, статус, публикацию в терминале и необязательный сценарий.
- Источник личного предложения сам по себе не сообщает о нём терминалу. Явная публикация допускается авторским сценарием; по умолчанию она выключена.
- Исход торга и согласованная цена сохраняются. Выплаты и вечернее завершение имеют ключи однократного исполнения.

- [x] Показывать известные системе доставки: адрес, срок до утра, согласованная оплата и состояние. Не раскрывать частные обещания, ловушки и скрытую истину о посылке.
- [x] Подключить `_alert_*`: подтверждённая санкция имеет приоритет над жалобой/обязательством, затем новым предложением. Чтение снимает непрочитанный статус по стабильному событию.

- [x] Отделить отсутствие физической коробки от `Declaration.LOST`: ни уничтожение, ни ненахождение, ни переход дня не создают заявление за игрока.

- [x] Разрешить ручное заявление потери известной поступившей посылки до начала визита и до регистрации. Не ослаблять правила фиктивной выдачи или отказа ради этого действия.

## Работы: предложения и выполнение

- [x] Формировать терминальные предложения один раз за день/при появлении подходящих зарегистрированных посылок: 1–3, а при нехватке кандидатов — меньше.
- [x] Предлагать только реальные посылки живых местных жителей. Одна посылка не имеет конкурирующих активных предложений.
- [x] Зафиксировать доплату терминала; стартовое значение равно базовой оплате выдачи. Активность добровольная, общий лимит двух принятых доставок убирается.
- [x] Добавить редкие личные предложения: вероятность 10%, регулируемый тестовый минимум одного за день при наличии кандидата, сценарное назначение. Долгая фаза и повторный разговор не перебрасывают выбор.
- [x] Добавить варианты согласия, отказа и одного запроса +50%. Стартовый шанс согласия на торг — 50%, авторская настройка; результат повторно не бросается. Отказ NPC в повышении цены сохраняет базовую доплату; отказ игрока от доставки завершает предложение допуслуги, сохраняя обычное получение.
- [x] Частное обещание не создаёт системный штраф или автоматическую запись адреса в терминале. Срыв создаёт значимую память NPC и претензию/реакцию по характеру при следующей встрече.
- [x] Реализовать один авторский сценарий доставки-ловушки с принудительным включением для теста. Встреча провоцирует столкновение; диалог закрывается перед боем, скрытый сценарий не выдаётся терминалом.
- [x] Сохранить вручение настоящей коробки у адреса через обычные проверки принадлежности, состояния, осмотра и отказа.
- [x] Обычная оплата и согласованная доплата начисляются однократно только при успешной выдаче. При отказе получателя доплаты нет, коробка остаётся физическим предметом.
- [x] Сон завершает невыполненное обязательство без выдачи, дублирования или переноса коробки на склад; далее доступно обычное получение без доплаты.

## Критерии завершения

- Заметки и уведомления переживают перезапуск и не смешиваются между посылками с одинаковым номером.
- Жалоба показывает известную причину и фактический штраф; скрытые сведения остаются скрытыми.
- Потеря до/после регистрации доступна вручную и фиксируется однократно. Уничтожение, отсутствие и смена дня сами её не объявляют.
- Терминал и NPC предлагают корректные реальные заказы; принятие всех предложений разрешено без прежнего лимита двух.
- Торг не перебрасывается; отказ от допуслуги не блокирует основное обслуживание.
- Ловушка воспроизводима, а срыв частного обещания имеет личные последствия.
- Доставка, отказ, сон и повторная запись не дублируют коробки и выплаты.
