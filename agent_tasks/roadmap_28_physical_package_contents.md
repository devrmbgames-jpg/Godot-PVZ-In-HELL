# R28 — Физическое содержимое и пустые посылки

Status: **PLANNED**

## Task state

### Goal

Аптечки, хлеб и другое содержимое — RigidBody3D, высыпаются при распаковке; коробка становится пустой, эффекты переходят на содержимое.

### Constraints / acceptance

- Для каждого существующего игрового типа посылки создать хотя бы физический placeholder с соответствующим эффектом, в том числе токсичный. Состав и эффекты настраиваются ресурсами.
- Пустая коробка не наносит исходный урон/токсичность/взрыв и не генерирует содержимое повторно. Сохранить учёт отправления и отметку распаковки.
- Реальное содержимое сохраняет свои эффекты после извлечения, доступно для захвата/еды/аптечки по типу. Не менять addons, preserve authored IDs and unrelated edits.
- Учесть осмотр клиентом в кабинке, удаление/отказ и сохранение физического владения через Relationships.
- Dev only; master read-only. R25 документация выполняется последней.
