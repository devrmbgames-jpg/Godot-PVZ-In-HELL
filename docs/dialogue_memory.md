# Авторская память NPC в диалогах

Параметры принадлежат постоянному NpcRecord внутри C_District.people, по npc_id.
NpcDialogueMemoryService выполняет записи; общий NpcDialogueContext предоставляет ровно
пять операций. Улица и обслуживание обращаются к одной личности. Закрытый ctx не пишет;
клиент без постоянной районной личности возвращает false/null и не создаёт личность.

| Операция | Контракт |
| --- | --- |
| set_tag(name) | Установить true, повтор безопасен. |
| get_tag(name) | Отсутствие → false без записи. |
| set_val(name, value) | Исходный Variant, включая явный null. |
| get_val(name) | Один аргумент, отсутствие → null без записи. |
| add_val(name, amount) | Только int/float с обеих сторон; отсутствие начинает с 0. |

int + int остаётся int, наличие float даёт float, отрицательные приращения разрешены.
bool и явный null не являются числом. Отказ add_val оставляет значение неизменным и
выводит авторское предупреждение. Каждый новый осознанный вызов прибавляет снова.
Панель блокирует повторный технический advance до завершения текущего await.

Теги и значения имеют разные пространства имён. Они не заменяют NpcMemory, деньги,
здоровье, отношения или квесты. Авторский тег holds_grudge не меняет настоящий
holds_grudge(): тот читает личные социальные инциденты текущего игрока и черту злопамятности.

Пример ниже компилируется установленным Dialogue Manager в GUT. Ветка remember_gift —
только учёт **уже подтверждённой** передачи 10 монет экономическим владельцем. Входить в неё
можно после успешной передачи; сама ветка не списывает деньги и не выдаёт подтверждение.
Имена/реплики служат примером, не становятся каноном игровых персонажей.

```dialogue
~ greeting
if not ctx.get_tag("visited")
    $> ctx.set_tag("visited")
    {{ctx.speaker_name()}}: Привет, новичок...
else
    {{ctx.speaker_name()}}: А, это ты...
=> END

~ remember_gift
$> ctx.add_val("taked_money", 10)
if ctx.get_val("taked_money") > 300
    {{ctx.speaker_name()}}: О! Мой любимый спонсор!
else
    {{ctx.speaker_name()}}: Спасибо.
=> END

~ optional_counter
if ctx.get_val("optional_count") != null
    {{ctx.speaker_name()}}: Счётчик: {{ctx.get_val("optional_count")}}
else
    {{ctx.speaker_name()}}: Пока не считали.
=> END
```

Схема 27 сохраняет коллекции через SaveDataCodec. DialogueValueCodec отделяет пользовательские
словари от служебных envelopes, сохраняет builtin-типы Array/Dictionary и значения PackedArray.
Имена type, definition и invalid внутри значения остаются данными. NodePath допускается как
буквальное значение, никогда как ссылка на тело или долговременная идентичность.

Runtime допускает любой Variant; Object/Node/Resource/RID/Callable/Signal, включая пустые
контейнеры с Object-типом, не представимы на диске. Такие значения, циклы и превышение
глубины 16 дают invalid с понятным путём к авторскому ключу. Save preflight отклоняет весь
snapshot до замены файла. Никакого преобразования в строку/null или пропуска ключа нет.
Старые схемы отклоняются с сохранением файла. Новая игра создаёт пустые коллекции.
