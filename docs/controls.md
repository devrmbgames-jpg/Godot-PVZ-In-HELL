# Управление прототипом

| Кнопка | Действие |
| --- | --- |
| WASD | Движение |
| E | Основное контекстное действие: взять/отпустить, иначе использовать |
| F | Дополнительное использование, когда у объекта есть второе доступное действие |
| ЛКМ | Активировать предмет в руке; для обычного предмета — бросить; выстрел/атака подключаются тем же контрактом |
| ПКМ | Альтернативная функция предмета (блок/прицел/режим); для обычного предмета — вращение |
| Alt + ЛКМ/ПКМ | Принудительный бросок/вращение инструмента вместо его функции |
| Space / C | Прыжок / приседание |
| Esc | Освободить/захватить курсор |

E сначала проверяет возможность подбора. Если предмет нельзя взять, выбирается доступное использование. Например: пульт смены использует E; переносимый предмет с функцией показывает E «Взять» и F для своей функции. При удержании E отпускает предмет. F не дублирует действие, уже выбранное для E.

Один ввод выполняет одно выбранное действие. Если основное и дополнительное взаимодействия назначены на одну кнопку, основное имеет приоритет и само выбирает доступную операцию. Подсказки читают InputMap и скрывают дублирующиеся назначения. Функции инструмента резервируют свои кнопки даже без подходящей цели: неудачное сканирование не бросает сканер.

Все будущие механики используют `InteractionAction` и `C_InteractionActions`. Лечение, оружие, сканер и другие системы не должны независимо исполнять тот же сырой ввод после маршрутизатора.

Панель слева показывает номер цикла, фазу и следующий шаг. При смене фазы появляется крупное уведомление. Начало и завершение смены — E на пульте; сон вечером — E у места отдыха.

Каждое утро в зоне приёмки появляются восемь посылок. Если места нет, освободите его: поставка продолжится, старые коробки останутся на своих местах.

Сканер лежит на столе терминала рядом со стартом. Возьмите его на E, наведитесь на коробку с расстояния до 3 м и нажмите ЛКМ. Звуковой сигнал и номер подтверждают регистрацию; повторное сканирование возвращает тот же номер. Терминал открывается на E со свободными руками или на F со сканером в руке. Реестр показывает посылки, зарегистрированные в текущем цикле; закрыть — E, Esc или кнопкой.
