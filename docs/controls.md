# Управление прототипом

| Кнопка | Действие |
| --- | --- |
| WASD | Движение; во время Push: W — толкать, A/D — поворачивать, S — отпустить |
| E | Взять/заменить предмет по таблице ниже; отпустить Carry/Push; иначе действие цели |
| F | Альтернативная замена руки или отдельное доступное действие цели |
| ЛКМ / ПКМ | Использовать правую / левую руку; при Carry — бросить / вращать Carry |
| Alt + ЛКМ / ПКМ | Бросить предмет из соответствующей руки, когда руки активны |
| R + мышь | Вращать разрешённый hand-item: сначала primary, иначе secondary |
| G, короткое нажатие | Положить один предмет: Carry → левая → правая |
| G, удержание | Показать заглушку контекстного колеса; короткого сброса не происходит |
| Space / C | Прыжок / приседание |
| Esc | Освободить/захватить курсор; закрыть Terminal или закончить рисование |

По умолчанию primary — правая рука, secondary — левая. Опция `C_GrabControl.swap_hand_controls` в Inspector меняет управление и выбор E/F, сохраняя физические слоты и anchors.

| Состояние рук | E на hand-item | F на hand-item |
| --- | --- | --- |
| Обе свободны | В primary; для предмета с ограничением — в разрешённую руку | Отдельной замены нет |
| Одна занята | В свободную руку | Заменить занятую |
| Обе заняты | Заменить primary | Заменить secondary |

Новый предмет проверяется до освобождения старого. Неподходящая рука, препятствие, чужое владение или недоступный предмет не приводят к потере текущего. Carry занимает отдельный слот, даже когда обе руки заняты.

При Carry, Push, рисовании или Terminal предметы остаются в руках, но опускаются ниже/за камеру. Приоритет: Terminal/modal → рисование → Push → Carry → руки → обычное вращение. Освобождение одного capture не поднимает руки, пока остаётся другой. Конфликтующий ввод не передаётся рукам в тот же тик завершения режима.

У Carry сохраняются E «Отпустить», ЛКМ «Бросить», ПКМ + мышь «Вращать». F позволяет использовать отдельное действие цели, например Terminal или тележку. Во время Push E/S отпускают тележку, F может открыть доступный Terminal; мышь не управляет скоростью поворота тележки. Во время Terminal G и кнопки рук заблокированы.

Ручное вращение Scanner отключено. Для других предметов настройки `manual_rotation_enabled`, `rotation_axis` и `reset_rotation_on_pickup` задаются в Inspector; Bucket использует Y_ONLY со сбросом при поднятии. Во время вращения то же движение мыши не поворачивает камеру. Использование руки имеет приоритет над R.

Два сканера находятся у Terminal. Возьмите сканер, наведитесь на посылку с расстояния до 3 м и нажмите кнопку его руки. Сигнал и номер `№001` подтверждают регистрацию; повторное сканирование сохраняет номер. Номера не сбрасываются при смене дня и переиспользуются после завершения складского lifecycle. Terminal открывается на E с активными руками или F при Carry; закрывается на E/Esc/кнопку. Реестр включает активные посылки всех дней и последнюю завершённую.

Каждое утро поступают восемь посылок. Если места нет, освободите зону: поставка продолжится. Начало/завершение смены — E на пульте; сон вечером — E у места отдыха.

Маркер лежит у сканеров на столе Terminal. Возьмите его, наведитесь на посылку и нажмите кнопку руки: включится рисование с янтарным указателем. Удерживайте ту же кнопку и двигайте мышь, чтобы рисовать; отпустите, чтобы перенести кончик без линии. E или Esc завершает режим и возвращает обзор. Штрихи остаются на коробке при переносе и вращении. Маркер не распознаёт текст и не записывает расположение в Terminal. Подробный контракт и граница сохранения R21: [маркировка посылок](package_marking.md).

В складе стоит стеллаж: ячейки 01–03 снизу, 04–06 сверху. Положите посылку в выбранную ячейку обычным физическим переносом; какую метку рисовать и как организовать хранение, решаете вы.

Будущие инструменты используют `DEF_InteractionAction` в `C_InteractionActionSet`; PRIMARY означает действие самого hand-item независимо от выбранной руки. Новая система не должна повторно обрабатывать уже маршрутизированный сырой ввод.
