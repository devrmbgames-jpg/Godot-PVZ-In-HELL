# R23: маршрут и доказательства вертикального среза

Ручная приёмка: `qa_tasks/full_day.md`. Полное прохождение пока не подтверждено. Проверки отдельных механик не заменяют прохождение дня обычными действиями.

## Фиксированный состав

`def_delivery_morning_supply.tres` доставляет восемь определений. ID первого утра: `base_supply:1:<key>`. Форма коробки может различаться между authored-вариантами; состав и назначение воспроизводимы.

| key | Назначение |
| --- | --- |
| books | Обычный клиент без челленджа; правильная выдача и отдельная декларация Terminal |
| glass | Хрупкая коробка; Light On, клиент не принимает повреждённую/вскрытую |
| clothes | Добровольный отказ; Light от прихода до физического ухода |
| bottles | Хрупкая жидкость; Gaze; ToxicArea при повреждении, ToxicResidue при разрушении |
| tools | Floor; содержимое bubble_wrap |
| equipment | Тяжёлая хрупкая коробка; клиент на день 11, carry-over |
| oil | Жидкость; свободная коробка для размещения/препятствий |
| power_cells | Хрупкая коробка; Explosion при разрушении |

Первый день содержит пять доступных клиентских событий: ordinary, careful, voluntary_refusal, gaze, floor. Отложенное equipment не должно блокировать закрытие смены. Light On/Off — одна семья; arrival-to-departure — вариант жизненного цикла, а не четвёртая семья.

## Маршрут обычными действиями

Маршрут для игроков и запись результата перенесены в [qa_tasks/full_day.md](../qa_tasks/full_day.md). Здесь остаются состав сценария и автоматические доказательства.

## Автоматизация и ограничения

M1: статическая проверка восьми определений/семей/late-event/двух опасных эффектов PASS. Строгий `challenge_light-20261002-145614714.log` PASS: Light Off остаётся отдельной тестовой копией определения ordinary; production ordinary не получает челлендж. Тестовый слот изолирован. Эта fixture не доказывает полный день.

Отладочный экран сохраняет условия/таймеры клиентов и задач. Опасные эффекты дополнительно показывают TTL, состояние разрешения, политику потери владельца и ожидаемое удаление; вывод ограничен четырьмя строками и счётчиком оставшихся эффектов.

Ручная приёмка после автоматизации: полный маршрут без debug-команд/перезагрузки, читаемость маркировки и HUD, ощущения боя/броска/перемещения, звук и gamepad. Headless не подтверждает эти свойства.
