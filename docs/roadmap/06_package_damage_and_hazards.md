# ТЗ 06 — Повреждение посылок и опасное содержимое

## Цель

Сделать обращение с коробками значимым и опасным.

## Package Damage

Package реагирует на:

- сильный удар;
- падение;
- столкновение с другим предметом;
- бросок;
- недопустимый наклон;
- намеренное вскрытие.

Damage зависит от физического события и свойств конкретной Package.

## Package HP / Integrity

У каждой Package есть количественный запас прочности — HP/Integrity, аналогичный по поведению Health игрока.

- валидный damage уменьшает текущее значение;
- состояние ограничено диапазоном от нуля до максимума;
- ноль означает разрушенную Package и может стать trigger для Hazard;
- Damaged/Destroyed — состояния, но они не заменяют количественный HP.

В реализации допустимо использовать отдельный `C_PackageIntegrity`, чтобы не смешивать actor Health и состояние посылки, но damage должен проходить через общий damage pipeline/contract.

## Impact severity

Физические удары классифицируются как минимум на:

- weak;
- medium;
- strong.

Severity вычисляется из физического события и затем преобразуется в HP damage с учетом характеристик конкретной Package. Fragile имеет более низкие допустимые пороги/устойчивость.

## Bubble Wrap

Package может иметь модификатор защиты "пузырчатая пленка".

Защита имеет уровень, способный нивелировать weak / medium / strong impacts. Impact, severity которого не превышает protection tier, не уменьшает Package HP. Более сильный impact продолжает обрабатываться обычным damage pipeline.

Сам protection state должен быть независим от источника. В будущем отдельный Consumable "Bubble Wrap" позволит игроку одним действием обмотать коробку на разгрузке и после этого обращаться с ней значительно грубее, вплоть до броска в окно при достаточном уровне защиты. Inventory/use этого расходника относится к R19.

## Fragile

Fragile имеет пониженный допустимый порог удара.

После превышения:

- Package получает Damaged;
- при выдаче возможен штраф;
- содержимое может породить Hazard.

## Heavy

Heavy:

- сильнее замедляет holder;
- потенциально наносит больше физического damage;
- стимулирует будущую покупку Cart.

## Liquid

Liquid имеет допустимый наклон относительно вертикали.

Если Package достаточно сильно/долго перевернута:

- содержимое портится;
- Package получает Damaged/Leaking;
- при соответствующем содержимом появляется Hazard.

## Вскрытие

Игрок может открыть любую Package по собственному решению.

Package получает Opened.

Позже это влияет на Customer Satisfaction, штрафы и события содержимого.

## Hazards MVP

### ToxicLeak

При разрушении подходящей Package создается опасная зона жидкости.

Она может:

- наносить periodic damage;
- воздействовать на Player и Customer;
- оставаться физическим препятствием/опасностью некоторое время.

### Explosion

При критическом damage подходящей Package:

- происходит взрыв;
- наносится radial damage;
- физические тела получают impulse.

## Экономическое последствие

Damage/Opened не обязаны немедленно списывать деньги.

Состояние Package сохраняется до Customer Delivery.

Если Customer пришел за поврежденной Package — применяется penalty/reaction.

Если клиент за ней не пришел, прямого штрафа может не быть.

## Критерий готовности

Fragile повреждается от грубого обращения, Liquid реагирует на переворот, а специальные Package способны породить ToxicLeak или Explosion.
