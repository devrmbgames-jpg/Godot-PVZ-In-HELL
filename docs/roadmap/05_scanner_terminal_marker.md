# ТЗ 05 — Сканер, терминал, маркер и полки

## Цель

Создать информационный workflow приемки.

## Scanner

Scanner — физический предмет.

При наведении на незарегистрированную Package и использовании LMB:

1. звучит beep;
2. Package получает регистрационный номер;
3. Package переходит в Registered;
4. Terminal получает запись;
5. на Terminal отображается номер, краткое содержимое и optional comment.

Повторный scan не создает новый номер.

## Terminal

Показывает список зарегистрированных посылок текущего цикла.

Для каждой:

- номер;
- краткое содержание;
- комментарий;
- status;
- при необходимости предупреждающие tags.

Terminal не показывает автоматически, на какой физической Shelf лежит коробка.

## Marker

Marker — физический инструмент.

При удержании Marker:

- RMB включает режим рисования;
- движение мыши оставляет линии на поверхности коробки.

Для прототипа достаточно свободного рисования. Распознавание текста не требуется.

Marker используется как mnemonic tool самого игрока.

## Shelf

В помещении находятся физически пронумерованные Shelf/ячейки.

Игрок сам решает:

- переписать номер на коробку;
- использовать номер Shelf;
- запомнить расположение;
- придумать собственную систему.

## Будущий upgrade

Предусмотреть данные для `LabelPrinter`, который позже сможет автоматически создавать наклейку после scan.

Полная реализация принтера не обязательна для первого vertical slice.

## Критерий готовности

Игрок сканирует Package, видит запись на Terminal, берет Marker, наносит собственную метку и кладет коробку на выбранную Shelf.
