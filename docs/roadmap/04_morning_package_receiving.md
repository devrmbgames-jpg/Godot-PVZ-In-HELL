# ТЗ 04 — Утренняя приемка посылок

## Цель

Создать первый полный рабочий процесс ПВЗ.

## Поставка

В начале Morning в зоне приемки появляются 6–10 физических Package.

Каждая имеет:

- внутренний ID;
- будущий номер отправления;
- краткое описание содержимого;
- Customer/recipient;
- PackageTags;
- параметры повреждения;
- состояние регистрации.

## PackageTags

Минимум:

- Normal;
- Fragile;
- Heavy;
- Liquid.

Теги могут сочетаться:

```text
Heavy + Fragile
Liquid + Fragile
Normal
```

## Начальное состояние

Новая посылка:

```text
Unregistered
NotScanned
Closed
Undamaged
```

До регистрации она не может быть корректно выдана клиенту.

## Сортировка

После регистрации игрок физически переносит коробку и сам выбирает место хранения.

Игра не должна автоматически ставить Package на правильную Shelf.

## Допустимые ошибки

Игрок может:

- положить не туда;
- забыть номер;
- оставить в проходе;
- повредить;
- вскрыть;
- потерять;
- посмтроить из посылок и обьектов башню по среди комнаты.

Это часть gameplay, а не ошибка системы.

## Критерий готовности

Morning создает разные физические коробки. Игрок может зарегистрировать и разложить их без автоматической коррекции своей организации.
