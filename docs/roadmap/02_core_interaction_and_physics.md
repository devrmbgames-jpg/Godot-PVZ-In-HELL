# ТЗ 02 — Базовое взаимодействие и физические предметы

## Цель

Создать единый interaction framework для объектов мира.

## Interaction target

Игрок имеет один активный target перед собой.

Выбор учитывает:

- дистанцию;
- направление взгляда;
- доступность;
- приоритет;
- отсутствие препятствия между игроком и объектом.

## Контекстная подсказка

Возле прицела отображаются только реально доступные действия.

Примеры:

```text
[E] Взять
[E] Открыть
[F] Использовать
[LMB] Бросить
[RMB + Mouse] Вращать
```

## Physical Grab

Для переносимых объектов:

- E — взять;
- E повторно — отпустить;
- LMB — бросить;
- RMB + Mouse — вращать предмет.

Held object остается физическим и продолжает взаимодействовать с окружением.

Его позиция и ориентация стремятся к target pose физически, без покадровой телепортации transform.

## Ограничения MVP

- один holder держит один объект;
- held object не должен нестабильно сталкиваться с собственным holder;
- стены и мебель физически ограничивают движение held object;
- слишком далеко застрявший предмет автоматически отпускается;
- release сохраняет текущую скорость;
- throw добавляет направленный импульс.

## Carry penalty

C_Grabbable определяет gameplay-влияние переноски:

- speed multiplier;
- acceleration multiplier.

Легкий объект может не замедлять игрока.

## Иммерсивные случаи

Система должна позволять:

- бросить тяжелую коробку в клиента;
- случайно ранить себя/клиента физическим предметом;
- загородить проход;
- подпереть дверь;
- использовать коробку как платформу.

## Критерий готовности

Игрок берет коробку, переносит, упирает в стену, вращает, отпускает и бросает. Коробка все время остается участником физической симуляции.
