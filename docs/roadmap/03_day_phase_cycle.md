# ТЗ 03 — Цикл игрового дня

> **Implementation coverage:** Implementation coverage: **R03**, persistence/next-day continuation in **R21**.

## Цель

Создать четыре фазы и единый переход между ними.

## Morning

Не ограничено временем.

Доступно:

- приемка;
- уборка;
- сканирование;
- сортировка;
- терминал;
- заказ расходников;
- подготовка помещения.

Клиентские события Day не запускаются.

## Day

Основная смена.

Ограничена количеством запланированных customer events, а не временем.

После завершения всех обязательных событий открывается переход в Evening.

## Evening

Не ограничено временем.

Доступно:

- ПВЗ;
- внешняя зона;
- торговцы;
- квесты;
- покупки;
- подготовка помещения.

## Night

Короткая переходная фаза.

SleepPoint:

- завершает день;
- фиксирует результаты;
- обрабатывает pending orders;
- сохраняет persistent state;
- создает следующий Morning.

## Authoritative state

Должно существовать одно состояние CurrentDayPhase.

Другие systems проверяют фазу через него, а не самостоятельно вычисляют время суток.

## Переходы

```text
Morning
→ StartShift
→ Day
→ CustomerScheduleComplete
→ Evening
→ Sleep
→ Night
→ NextDayMorning
```

## Критерий готовности

Игрок может пройти полный пустой цикл Morning → Day → Evening → Night → Morning без перезагрузки игры.
