# Agent configuration

Repository-scoped AI configuration is intentionally small:

- `skills/develop/` — right-sized implementation workflow.
- `skills/gecs-v8/` — GECS-specific architecture/API workflow.
- `skills/gut-testing/` — GUT-specific testing workflow.
- `skills/professional-game-design/` — player-facing design workflow.
- `.codex/` — optional bounded reviewer/validator roles and context/output limits.

Root `AGENTS.md` contains only always-on project invariants, routing, and execution permissions.
