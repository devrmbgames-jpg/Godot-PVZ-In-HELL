## Goal / acceptance

Утренний внешний враждебный вор, никогда не клиент/получатель/курьер.
Видит и физически уносит одну подходящую посылку; при первом ударе игрока один выбор
50/50: бросить и бежать либо атаковать. При 0 < HP ≤20% max — бросить и скрыться;
смерть приоритетнее. Кража не меняет истинного получателя/регистрацию и не становится выдачей.
Все appearance, чужие конфликты, физические и save/lifecycle гарантии Source обязательны.

## Current

План, не реализация. Владелец подтвердил первый удар/один выбор и приоритет кражи
при враждебном статусе. Вид игрока сам по себе не переключает на атаку.
Частота один вор за включённое утро — только прототипное предложение.
