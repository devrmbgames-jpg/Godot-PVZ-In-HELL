# R24 — Проверка новых механик игроком

Artifact: **SUPPORT**
Источник: R24. Результат: **ОЖИДАЕТ ИГРОКА**.

M1 реализован и доступен в Windows91e00d6c, main/test startup PASS. Запуск тестовой карты: `.export/TEST_LEVEL.cmd`. Интервалы и уход уже доступны в a3a7c276.

- [ ] Дойти до секции «ЗАМОК / ДВЕРЬ» (двери около x0/x4,z12). Целый замок нельзя обойти обычным «Отпереть». Нож/молоток наносят урон; после разрушения замок исчезает и дверь открывается штатной кнопкой.
- [ ] Разбить дверь рядом. Створка исчезает; пройти, перенести посылку через освободившееся место. Невидимая коллизия не мешает.
- [ ] `debug_hud off/on` скрывает/возвращает HP и инструкции над тестовыми дверями.
- [ ] Дойти до «РАСПАКОВКА» (x−12/−6/0,z−18). Навести на коробку и нажать F («Вскрыть посылку»). Из первой выходит полка1,5×3×1,5м с двумя секциями, из других — ровно5 аптечек/5 кусков хлеба. Содержимое появляется рядом на полу, предметы не наложены друг на друга.
- [ ] Хлеб/аптечки подобрать в инвентарь. Еда утоляет голод, аптечка лечит при неполном HP; расходуется только использованный предмет.
- [ ] Полку перенести, поставить на пол, дождаться устойчивого положения и закрепить молотком. Положить посылки в обе секции; полка не падает и не перекрывает внутренний объём сплошной коллизией. Затем открепить через F.
- [ ] После сохранения/загрузки сломанные двери и замки остаются сломанными, закреплённая полка остаётся закреплённой, коробки не выдают содержимое повторно.
- [ ] Клиент, который дошёл до выхода, исчезает там. Заблокированный уходящий NPC остаётся минимум180с, затем удаляется. До следующего клиента пауза30с; её видно в debug HUD.

Шаблон клиента ещё ждёт реализации; сценарии добавлять по мере готовности.

## M2 — торговля мебелью и доставка

- [ ] В Evening открыть торговца через F. В каталоге есть большая полка3×3×1,5м:180 денег,75кг. При покупке она появляется в отмеченной зоне рядом с торговцем, а не в инвентаре. Деньги списываются один раз.
- [ ] Перенести полку штатным физическим хватом, поставить устойчиво на пол, закрепить молотком. Секции доступны для посылок. Проверить массу/усилие перемещения и отсутствие провала за пол.
- [ ] Заставить зону выдачи мебелью/предметами. Если свободного места нет, новая покупка сообщает «Освободите место» и не списывает деньги. Освобождение места позволяет повторить покупку.
- [ ] Выбрать отдельную кнопку доставки домой:180+30=210, утро следующего дня. Сразу мебель не появляется. Утром появляется в зоне домашних заказов; при занятой зоне ждёт освобождения, повторной оплаты нет.
- [ ] Сохранить/загрузить оплаченный заказ до доставки, затем доставленную полку. Нет повторного списания или второй полки. Потреблённый заказ не появляется заново.
- [ ] Для другого торговца назначить копию DEF_TraderProfile с другим каталогом/расписанием. Окно и подпись показывают нужные часы; вне них покупка заблокирована. Пример def_trader_medical: день2,4,…, только Morning, аптечки.
- [ ] Проверить читаемость скроллируемого каталога, цены доставки и подписи зоны выдачи на основной и тестовой картах.

Автоматическая проверка использует настоящую main_level без визуального запуска. Полный игровой срез, перенос/закрепление мебели и удобство UI проверяет игрок.

## QA04 / R24 съедобные останки — доступно в Windows e15bf73a

- [ ] Ножом или молотком убить клиента/торговца. Ожидается: вместо живой модели три красных куска мяса с косточкой, иногда аптечка; никто не продолжает ходить/атаковать/торговать. Проход свободен.
- [ ] Подобрать мясо через E, открыть инвентарь и съесть. Каждый кусок расходуется и уменьшает голод на25. Несмертельный удар не создаёт мясо, повторные удары/загрузка не дублируют остатки.
- [ ] Клиентский визит/челлендж завершаются при смерти, но остатки остаются. Сохранение и следующая смена сохраняют подобранное/неподобранное мясо, не оживляют торговца.
- [ ] Если торговец умер во время открытого окна торговли, окно закрывается и управление возвращается игроку.

Временная заглушка по последнему разрешению владельца сразу создаёт мясо; промежуточный труп с разделкой в текущую приёмку не входит.

## M5 — шаги, камера и виньетки

- [ ] Пройти/пробежать рядом с клиентом и торговцем. Шаги игрока слышны; NPC звучит со своей стороны и затихает вдали. Стояние, воздух, смерть и открытое модальное окно не создают шаги.
- [ ] При ходьбе камера слегка покачивается, остановка возвращает её в нейтральное положение. Резкий поворот остаётся отзывчивым; прицеливание комфортное. Настройки CharacterFeedback bob_enabled/reduced_motion отключают покачивание.
- [ ] Получить урон / проголодаться / посмотреть на запрещённое существо: края экрана соответственно красные / янтарные / фиолетовые; центр и UI читаются. Исцеление/еда/завершение челленджа убирают соответствующую причину.
- [ ] debug_hud off скрывает отладку, но сохраняет обычные виньетки и шаги. on возвращает отладку.

Автоматически проверены409/409 тестов крупного этапа; звук, цвет, комфорт и полный игровой срез ожидают игрока.

## M3 — условия завершения смены (в следующей сборке)

Настройки находятся в компоненте C_DayCycle узла Entityes/DaySession, группа Shift completion. По умолчанию сохраняется ожидание обслуживаемых визитов.

- [ ] Включить minimum_shift_seconds=240: станция смены и debug HUD показывают оставшиеся секунды, завершение блокируется до истечения времени. Morning/Evening не расходуют этот таймер, новая смена начинает с нуля.
- [ ] require_empty_customer_room: пустой customer_room_path ждёт удаления всех живых клиентов. Для границы конкретного здания добавить Area3D с охватывающей здание коллизией и маской NPC, указать путь относительно DaySession. Клиент снаружи не блокирует, внутри блокирует; торговец/останки не считаются.
- [ ] require_all_planned_arrivals ждёт и незарегистрированные запланированные на сегодня посылки. Зарегистрировать их, дождаться клиентов. Будущие и явно закрытые визиты не блокируют.
- [ ] Отключить require_finished_customers для завершения сразу после прихода всех клиентов, если другие выбранные условия выполнены. Включённые условия сочетаются: каждое должно выполниться. day_next в консоли показывает ту же причину отказа.
