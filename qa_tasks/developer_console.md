# Справка и прокрутка консоли

Источник: [Developer Console Testing](../agent_tasks/developer_console_testing.md).

Готовность: **ГОТОВО К РУЧНОМУ QA**, низкий приоритет. Результат: **НЕ ПРОВЕРЕНО**.

Проверять в последней Windows сборке:

- [ ] Открыть консоль, вызвать `help`. Видны группы команд, синтаксис и примеры; `help <команда>` объясняет параметры и ограничения, неизвестное имя выдаёт понятную ошибку.
- [ ] Получить вывод на несколько экранов, прокрутить вверх/вниз колесом и полосой прокрутки; проверить PageUp/PageDown. Вводить команды по-прежнему можно, игрок/камера от прокрутки не двигаются.
- [ ] Закрыть/открыть консоль и повторить. Встроенные команды и `debug_help` остаются доступны.
- [ ] Выполнить предложенные в справке сценарии еды/инвентаря, торговца/заказа, клиента/челленджа и сохранения в отдельный тестовый слот. Вывод сообщает действительный результат; недоступное действие объясняет причину.

- [ ] При активном диалоге открыть консоль, дождаться завершения диалога/таймера: курсор остаётся доступным. Закрыть консоль, проверить возврат управления и отсутствие захвата клавиш игроком.
- [ ] `help inventory`: создать хлеб, убедиться в слотах с нуля, съесть и увидеть снижение голода. Полный инвентарь/мебель/неверный слот дают ERROR без потери предметов.
- [ ] `help trader`: проверить магазин по расписанию, купить большую полку в зоне выдачи, заказать курьера с доплатой, проверить следующий Morning через обычные переходы.
- [ ] `help npc`: проверить melee/ranged слоты0..2; неправильный слот/дистанция/кулдаун не сбрасывают текущую атаку. nav_info показывает реальный NavigationAgent. Смерть даёт мясо сразу; corpse_info сообщает released, meat_spawn создаёт съедобную заглушку.
- [ ] `progress_set target 0.5` на hold-вентиле вращает колесо и сообщает progress_changed, не вызывает gameplay completion. Активный/completed hold запрещён. Immediate-кнопка принимает0/1.
- [ ] Morning: save_write qa_console / save_load qa_console. Плохой путь, Day, активное толкание/тележка/предмет в руках/диалог запрещают запись и загрузку без изменения мира или слота. Обычный autosave не перезаписывается.
