# Машина — ручная приёмка стоянки и входящих коробок

Status: **PENDING_OWNER_QA**

Автоматическая проверка: [появление машины](../agent_tasks/district_truck_morning_spawn.md). Этап: [утренняя машина](../agent_tasks/district_morning_truck.md).

Проверять текущую сцену main_level с новой сессией. Windows QA этого этапа будет подготовлена после итоговой интеграции; предыдущая сборка лута/торговли ещё не содержит машину.

## Приёмка владельцем

- [ ] Поле ReceivingZone.truck_parking указывает на TruckParking. Стоянка находится в авторской зоне DebugMarkers/CarZone; машина не перекрывает дверь, нужный проход или склад.
- [ ] Перемещение/поворот TruckParking меняет место/поворот машины. Пользовательская сетка навигации сохранилась.
- [ ] Утром появляется одна машина, существующая дверь открывается. Прибытие/движение не воспроизводятся.
- [ ] В car.tscn список cargo_slots ссылается на 12 маркеров CargoSlots и задаёт порядок нижних/верхних мест. Изменение маркера отражается на размещении груза.
- [ ] Коробки доступны для ручного выноса: не застревают в стенках, не проваливаются через пол и не перекрываются при укладке.
- [ ] При заполнении кузова поставка ждёт. Вынос коробок освобождает место для остатка той же партии; долгое утро не создаёт лишние посылки.
- [ ] Терминал показывает поступления до регистрации; номер выдачи появляется только после обычной регистрации.
- [ ] Длительный перезапуск с частичной поставкой сохраняет поступившие коробки и остаток без повторного груза.

Запрет начала смены до разгрузки, игрок в кузове, финальное закрытие двери и обратный груз принадлежат следующим задачам. Отрисовка и субъективное удобство не проверялись автоматически.
