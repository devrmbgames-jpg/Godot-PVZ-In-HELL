# Настройки, управление и иконки — R30

Готово к проверке. Результат: **ожидает игрока**. Запустите `.export/LATEST.cmd`; убедитесь, что build_info.json содержит commit с R30 меню. Упрощённая сцена — `.export/TEST_LEVEL.cmd`.

## Сценарии

- [ ] Открыть настройки кнопкой меню. Мир, таймеры клиента и челленджа приостановлены; курсор доступен. Закрыть: мир продолжает работу, управление возвращается.
- [ ] Изменить громкость, полноэкранный режим, VSync, чувствительность мыши и стика, мёртвую зону. Каждый параметр действует; перезапуск сохраняет его. Звук/экран проверяются на настоящем устройстве.
- [ ] Включить уменьшение движения: покачивание камеры отключено, виньетка использует щадящий режим. Отключить и сравнить.
- [ ] Назначить новую клавишу взаимодействия: подсказка над предметом показывает её иконку, взаимодействие выполняется новой клавишей. Инвентарь, терминал, торговля, диалоги и настройки показывают актуальные иконки.
- [ ] Назначить комбинацию с модификатором: обе кнопки отображаются с плюсом. Несколько альтернатив отображаются через разделитель.
- [ ] Назначить занятую кнопку: показан конфликт. Отмена ничего не меняет; подтверждение удаляет пересекающееся назначение из другого действия. Проверить также комбинацию Ctrl+E при занятом E: два действия одновременно не выполняются.
- [ ] Во время capture отменить ввод кнопкой возврата или нажать «Отменить назначение»: прежнее назначение сохраняется. Клавиша консоли зарезервирована.
- [ ] Подключить геймпад: переключение устройства меняет подсказки. Назначить кнопку, оба направления оси и триггер; движение/камера реагируют с учётом мёртвой зоны. Переподключение геймпада сохраняет назначения.
- [ ] Переназначить клавиатуру: gamepad binding остаётся. Переназначить геймпад: keyboard/mouse binding остаётся. Escape/Back продолжают позволять выйти из настроек.
- [ ] Открыть настройки с посылкой в руках: после закрытия она остаётся в руках; продолжить движение/переноску/выдачу клиенту.
- [ ] Открыть диалог/инвентарь/терминал: кнопка закрытия закрывает текущий экран, настройки не открываются одновременно. Во время рисования она заканчивает рисование. Открыть консоль поверх настроек, закрыть консоль, затем настройки: курсор и управление восстановлены.
- [ ] Восстановить исходные настройки/управление; проверить UI, сохранить и перезапустить.
- [ ] С настоящим Xbox/PlayStation/другим устройством проверить читаемость кнопок. Редкие отсутствующие в наборе Kenney кнопки используют общую иконку устройства; запишите неудобные назначения для улучшения отображения.
