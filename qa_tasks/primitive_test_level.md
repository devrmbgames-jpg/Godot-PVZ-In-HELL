# Простая тестовая сцена

Источник: [Тестовая сцена и общий World](../agent_tasks/primitive_test_scene_shared_world.md).

Готовность: **ГОТОВО К ПРОВЕРКЕ реализованных механик**. Результат: **НЕ ПРОВЕРЕНО**.

Запуск: `.export/TEST_LEVEL.cmd` — отдельная Windows-сборка; в редакторе F6 для `content/scenes/primitive_test_level.tscn`. Основная карта доступна через `.export/LATEST.cmd`. Тестовая карта использует отдельный слот `primitive_test_level.pvzh`.

Ориентиры на карте:

| Зона | Объекты / сценарий |
| --- | --- |
| 01 Приёмка, северо-запад | Утренние посылки, Terminal и Scanner рядом с зоной 03; [полный день](full_day.md) |
| 02 Хранение | Два numbered shelves, возврат; номер/маркер/выдача |
| 03 Клиенты, север | Стойка выдачи, свободный маршрут Entry → Waiting; [диалоги](dialogue_and_customers.md), [челленджи](environment_and_challenges.md) |
| 04 Инструменты, запад | Три маркера, молоток, нож и коробка для фиксации, отдельные подставки |
| 05 Физика, запад | Тележка, физические слоты, placement areas, тяжёлые коробки и бочки |
| 06 Торговля, северо-восток | Торговец и OrderReceiving; [торговля/сохранения](commerce_and_persistence.md) |
| 07 Инвентарь | Еда, лекарство, упаковка; [бой/голод/инвентарь](combat_hunger_inventory.md) |
| 08 День, восток | ShiftConsole, SleepPoint; цикл, Night и следующее утро |
| 09 Окружение, юго-восток | Две двери, два окна, ящик; переключатель света у стойки |
| 10 Вентили, юг | Пять режимов E / hold F с интервалом 2 м |

Проверки:

- [ ] Запустить её выбранным разработчиком способом. Зоны обозначены, ключевые объекты расставлены примерно через 2 метра; проходы свободны и объекты не навалены друг на друга.
- [ ] Пройти между зонами и точками появления клиентов, переносить/выбрасывать предметы. Большой пол поддерживает всю игровую область; ничего не падает в щели/за край при обычной проверке.
- [ ] Выполнить связанные сценарии из [очереди QA](README.md) для всех готовых механик. Их правила соответствуют основной игре; у временно неготовой механики явно указан статус.
- [ ] Сравнить управление и доступные действия с основной сценой; после проверки основное сохранение не изменилось. Общую конфигурацию World и отсутствие двойного запуска отдельно проверяет разработчик.

QA-03–QA-13 остаются в очереди реализации: сетка инвентаря, труп/мясо, статус клиента, ×4, новые способы диалога, анимация ножа, вращение/сигнал вентиля, обход NPC, seam ИИ и внешние материалы. Пока эти пункты не отмечены готовыми в [замечаниях владельца](owner_qa_fixes.md), их отсутствие не является пройденной проверкой.
