## Ручная приёмка

- [x] Зарегистрировать утренние коробки местных жителей. В строках терминальных предложений показаны фактическая доплата, кнопки принятия/отказа и подсказки. В подробностях читаются адрес, срок до следующего утра и статус.
- [x] Принять предложение, закрыть и открыть терминал: статус остаётся принятым, кнопки повторного принятия скрыты. Коробка остаётся на своём месте, деньги за одно обещание не начисляются.
- [x] Отклонить другое предложение: указано, что допуслуга отклонена; обычное получение посылки остаётся доступным. Обновление списка и повторное открытие не создают нового предложения.
- [x] Оставить другую посылку выбранной, дождаться нового события. Информационная иконка обозначает предложение; предупреждение — жалобу/обязательство; критическая иконка — назначенный штраф. Одновременно показывается только наивысший непрочитанный приоритет.
- [x] Открыть подробности посылки с уведомлением: иконка снимается. После обновления, закрытия/открытия и перезапуска она не возвращается. Последующее решение по ранее прочитанной жалобе создаёт новое уведомление.
- [x] Проверить личную доставку, которую NPC не сообщил системе: раздел доставки, адрес, цена и сценарий отсутствуют в терминале. Явно опубликованное предложение видно, но содержание ловушки не раскрывается.
- [x] Ночью и при отсутствии физической коробки кнопки предложения отключены; подробности объясняют недоступность. Коробка не объявляется потерянной автоматически.
- [x] Открыть терминал клавиатурой, пройти Tab/Shift+Tab по строкам и действиям, принять/отклонить доставку: фокус остаётся на той же посылке. Закрытие возвращает управление игроку. Проверить мышь и отсутствие перекрытия кнопок.
- [x] Проверить длинный адрес, жалобу, большие суммы и масштабирование UI при обычном разрешении: строка, подсказки и описание читаются, элементы не перекрывают друг друга. Ввод примечаний, курсор и Undo сохраняют прежнее поведение.

Headless-проверки подтверждают действия реальных кнопок, фокус, сохранение чтения/решений и границы знаний. Субъективная читаемость, мышь и rendered-навигация ещё не проверялись.
